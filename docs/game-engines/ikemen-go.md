# Ikemen GO

Optional runtime for a 2D fighter cabinet.

Ikemen GO is an open-source fighting-game engine that can load **M.U.G.E.N-format** characters, stages, and screenpacks. It is a separate project from Elecbyte. Credit both if we use it.

Staff at a youth center do not install this. Volunteers building a dedicated fighter cabinet might.

## When we would use it

- A placement specifically wants a 2-player fighter
- All characters/stages on that box are original, public-domain, or reviewed homebrew
- Someone can maintain the build (updates, controls, exit-to-attract)

Default fleet software remains the [web terminal](terminal.md).

## License notes
