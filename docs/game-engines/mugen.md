# M.U.G.E.N — credit and license

Coin Op 4 Charity does **not** ship Elecbyte’s `mugen.exe` to youth-center staff.

We document M.U.G.E.N here because:

- the file formats (`.def`, `.cns`, `.air`, `.sff`, `.snd`) are the common language for 2D fan fighters
- any optional Ikemen GO cabinet we run is compatible with that format
- Elecbyte asked that the engine be used under their license and that the original work be recognized

If we load MUGEN-format characters or stages, this page is the credit.

## Credit

**M.U.G.E.N** (also written MUGEN) is a 2D fighting-game engine created by **Elecbyte**.

- Engine and original tools © 1999–2013 **Elecbyte**
- Official overview and documentation index: [https://elecbyte.com/mugendocs-11b1/mugen.html](https://elecbyte.com/mugendocs-11b1/mugen.html)
- Project home (historical): [http://elecbyte.com](http://elecbyte.com)
- Sample character **Kung Fu Man** and default stages/motifs are Elecbyte content bundled with the engine

Elecbyte is an independent team. Members have generally stayed anonymous. Credit the **project name and the organization**, not guessed personal names.

## License (plain language)

Elecbyte licenses the **M.U.G.E.N Environment** (the executable and the data files they ship for it) as **free for non-commercial use**. Other uses need their permission. The full text is in the engine `README` / license appendix that ships with official builds.

For this charity that means:

- Running the engine or MUGEN-format content in a free-play youth space is the kind of use the license describes as non-commercial.
- Do **not** sell a “Coin Op 4 Charity MUGEN game,” bundle `mugen.exe` into a paid product, or charge admission tied to that executable.
- Do **not** treat community “full game” downloads (DBZ packs, Capcom-vs packs, etc.) as licensed. Those are third-party packs. Most use commercial sprites Elecbyte never cleared.
- Character and stage *formats* are documented publicly; the sprites and audio inside a given pack still belong to whoever made or owns them.

If we ever need a use that is not clearly non-commercial, stop and ask — do not assume.

## What we will and will not run

**Allowed (after review)**

- Original characters and stages made by kids or volunteers
- Public-domain or permissively licensed art/audio packed into MUGEN formats
- Elecbyte’s own sample content (Kung Fu Man, Training Room, etc.) where the bundled sample license allows it

**Not allowed on charity stations**

- Sprite rips from Street Fighter, King of Fighters, Mortal Kombat, anime, or any living commercial catalog
- Paid or “complete game” MUGEN distributions Elecbyte did not authorize
- Teaching site staff to download random chars from dump sites

## How this relates to Ikemen GO

If we put a fighter cabinet on the floor, the runtime should be **[Ikemen GO](ikemen-go.md)** (open source, MUGEN-resource compatible), not the 2013 Elecbyte beta.

Still credit Elecbyte for the original engine and formats. Ikemen GO is a separate project with its own authors and license — see that page.
