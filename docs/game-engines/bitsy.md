# Bitsy

Smallest safe kid tool. Export is **HTML5**.

[Bitsy](https://bitsy.org) is a tiny editor for short exploration / story games. Hard to ship a 2GB build. Easy to review.

[PuzzleScript](https://www.puzzlescript.net) is the sibling pick for turn-based puzzles — same idea, HTML export. If we add a PuzzleScript page later, the rules are the same as this file.

Coin Op 4 Charity is not affiliated with Bitsy or PuzzleScript.

## Rules

- Original game or clear permission.
- Packaged HTML, not an editor login.
- Content OK for youth spaces.
- Bitsy is often keyboard / click — note that on the submit form if the station is stick-only.

## Why it’s here

Not every club game has to be a shooter. A five-minute Bitsy piece a kid wrote about their neighborhood is a valid Arrrcadé OS title if it passes review.
