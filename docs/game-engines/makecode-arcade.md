# MakeCode Arcade

Kid / classroom tool. Export must be **HTML5**.

[MakeCode Arcade](https://arcade.makecode.com) is Microsoft’s browser editor for simple sprite games. Blocks or JavaScript. Built for schools.

Coin Op 4 Charity is not affiliated with Microsoft or MakeCode.

## Floor

| | |
|--|--|
| Where | Tablets, Pi kiosks, Preview Lab, workshop machines |
| Kid submit? | **Yes** |
| What we run | Exported / shared game that plays in a page without a required sign-in |

## Rules

- Original games only for live stations (or assets you have permission to use).
- Prefer an export or embed that does not force a Microsoft account on a child at the cabinet.
- Content OK for youth spaces. No gore packs, no dating sims.
- Note controls for HID sticks when you submit.

## Hardware later

MakeCode can also flash some handhelds. That is optional STEM workshop gear, not a requirement for the terminal. The floor still wants a browser page.
