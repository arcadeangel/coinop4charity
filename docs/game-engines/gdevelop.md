# GDevelop

Next step after Scratch. Export must be **HTML5**.

[GDevelop](https://gdevelop.io) is open-source, no-code / low-code. Kids can build something that looks like a real arcade game without a compiler.

Coin Op 4 Charity is not affiliated with GDevelop or its publishers.

## Floor

| | |
|--|--|
| Where | Terminal if the HTML5 export is light enough for the tablet |
| Kid submit? | **Yes, with review** |
| What we run | HTML5 export, not the GDevelop desktop app |

## Rules

- Export HTML5. Test on a low-RAM tablet before you call it live.
- Original or licensed assets only.
- No account walls, no storefront inside the game.
- Reject huge WebGL dumps that hitch or overheat a club tablet — those can wait for a dedicated cabinet.

## When to use something else

If the export is too heavy, cut scope or move the title to a Pi / PC cabinet. Do not force Unity-class builds through this path.
