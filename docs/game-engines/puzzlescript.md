# PuzzleScript

Kid / classroom puzzle tool. Export is **HTML5**.

[PuzzleScript](https://www.puzzlescript.net) is an open, browser-based engine for turn-based block puzzles (Sokoban-style and similar). Games are a text script plus a tiny spritesheet. The share / export path is a web page.

Same class as Bitsy: small, easy to review, hard to hide a ROM pack inside. See also [bitsy.md](bitsy.md).

Coin Op 4 Charity is not affiliated with PuzzleScript.

## Rules

- Original puzzle or clear permission / public-domain script.
- Packaged or standalone HTML — not “open this editor login on the cabinet.”
- Content OK for youth spaces.
- PuzzleScript is usually keyboard (arrow keys / action). Note that on the submit form if the station is stick-only; map stick to arrows when you can.
- No commercial level packs you do not have rights to ship.

## Why it’s here

A kid can finish a real game in one sitting. Staff can read the whole script. That is the point of putting it next to Bitsy instead of next to MUGEN.
