# Arrrcadé OS / web terminal

This is the engine the fleet actually runs.

Live site: [https://coinop4charity.org](https://coinop4charity.org)

Source: [https://github.com/arcadeangel/coinop4charity](https://github.com/arcadeangel/coinop4charity)

## What it is

Browser terminal for free-play youth stations: attract mode, live games, global hi-scores, placement intake, and Make → submit → review → LIVE.

Kiosk-style boots use `?kiosk=1` (also `?arcade=1` / `#kiosk`). Staff setup lives in:

- `docs/staff-coding/on-site-guide.md`
- `docs/restoration/Tablet_Arcade_Station_Youth_Center_Setup_Guide.pdf`
- `docs/restoration/BSP-Y02_Web_Arcade_Controller_Guide.pdf`

## Credit

- Terminal software and custom games: **Coin Op 4 Charity** (open source in this repo)
- Individual live titles that are not ours must keep their own author credit on the game card and in the site footer or journal when permission was granted (example: Nyan Cat IV — creator permission)

Do not list Elecbyte or Ikemen GO on terminal-only cabinets. Those credits belong on fighter cabinets that load MUGEN-format content.

## Stick and exit

HID arcade sticks only for official station guides. Hold Start to exit a game back to attract, matching the on-site guide. Dance mats and Bluetooth speakers are not supported as controllers.
