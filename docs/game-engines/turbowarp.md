# Scratch / TurboWarp

Kid on-ramp. Export must be **HTML5**.

[Scratch](https://scratch.mit.edu) is the block editor most youth programs already know. [TurboWarp](https://turbowarp.org) packs a Scratch project into a page that can run without the Scratch website.

Coin Op 4 Charity is not affiliated with the Scratch Foundation or TurboWarp.

## Floor

| | |
|--|--|
| Where | Tablets, Pi kiosks, Preview Lab |
| Kid submit? | **Yes — first choice for younger kids** |
| What we run | Exported HTML page, not a live scratch.mit.edu link that needs an account |

## Rules

- Original project or remix with credit, appropriate for a youth center.
- Export HTML (TurboWarp “packager” or equivalent) so the kiosk does not depend on Scratch cloud, comments, or chat.
- No cloud variables that phone home. No “talk to strangers” uses.
- Stick / keyboard: document which keys move and which button is A / Start.

## Why not “just open Scratch in the browser”

Club tablets in kiosk mode should not dump kids onto a social site. A packaged page stays on our terminal.
