# Credits

Coin Op 4 Charity / Arcade Angels is an independent Nevada nonprofit project. Names below are credited for tools or ideas we use or point to. **None of these people or companies run this charity unless listed as a partner on coinop4charity.org.**

## Languages and platforms we point to

### Leaf Corcoran
Created **MoonScript** ([moonscript.org](https://moonscript.org)) and founded **itch.io** ([itch.io](https://itch.io), launched 3 March 2013).

MoonScript may be used for optional LÖVE cabinet games. See [`docs/engines/love2d-moonscript.md`](docs/engines/love2d-moonscript.md).

itch.io is a digital indie marketplace. This project places physical arcade machines in youth centers. We are not affiliated with itch.io, MoonScript, or Leaf Corcoran. Their public contact for itch.io is support@itch.io.

### LÖVE
[love2d.org](https://love2d.org) — optional runtime for dedicated cabinets only.

### Ikemen GO
[github.com/ikemen-engine/Ikemen-GO](https://github.com/ikemen-engine/Ikemen-GO) — optional fighting-engine path. Content rules: [`docs/engines/mugen-ikemen.md`](docs/engines/mugen-ikemen.md).

### M.U.G.E.N
Created by Elecbyte. Engine mention only. We do not redistribute Elecbyte or third-party commercial character packs.
