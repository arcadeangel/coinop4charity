# Credits

Coin Op 4 Charity is an independent Nevada nonprofit project. Names below are credited for tools or ideas we use or point to. **None of these people or companies run this charity unless listed as a partner on coinop4charity.org.**

## Default runtime

Games on the public terminal run as **HTML5 / JavaScript** in a kiosk browser. See [`docs/game-engines/html5.md`](docs/game-engines/html5.md).

## Kid authoring tools (export to HTML5)

- **Scratch** — Scratch Foundation, [scratch.mit.edu](https://scratch.mit.edu)
- **TurboWarp** — community Scratch packager, [turbowarp.org](https://turbowarp.org)
- **MakeCode Arcade** — Microsoft MakeCode, [arcade.makecode.com](https://arcade.makecode.com)
- **GDevelop** — [gdevelop.io](https://gdevelop.io)
- **TIC-80** — [tic80.com](https://tic80.com)
- **Bitsy** — [bitsy.org](https://bitsy.org)
- **PuzzleScript** — [puzzlescript.net](https://www.puzzlescript.net) (same class as Bitsy; page optional)

We are not affiliated with these projects. Kid submissions must be original or clearly licensed and packaged so a station does not depend on their social sites or accounts.

## Languages and cabinet engines

### Leaf Corcoran
Created **MoonScript** ([moonscript.org](https://moonscript.org)) and founded **itch.io** ([itch.io](https://itch.io), launched 3 March 2013).

MoonScript may be used for optional LÖVE cabinet games. See [`docs/game-engines/moonscript.md`](docs/game-engines/moonscript.md).

itch.io is a digital indie marketplace. This project places physical arcade machines in youth centers. We are not affiliated with itch.io, MoonScript, or Leaf Corcoran. Their public contact for itch.io is support@itch.io.

### LÖVE
[love2d.org](https://love2d.org) — optional runtime for dedicated cabinets only.

### Ikemen GO
[github.com/ikemen-engine/Ikemen-GO](https://github.com/ikemen-engine/Ikemen-GO) — optional fighting-engine path. Content rules: [`docs/game-engines/mugen-ikemen.md`](docs/game-engines/mugen-ikemen.md).

### M.U.G.E.N
Created by Elecbyte. Engine mention only. We do not redistribute Elecbyte or third-party commercial character packs.
