# Submit runtime

Rules for games that enter Make → review → LIVE on the terminal.

This is not a tutorial for Godot or Phaser. It is the contract a submitted build has to meet so it can sit next to Circuit Runner and Nyan Cat IV on a youth-center stick.

## Allowed authoring tools

Original work only. These are fine if the export is a browser game or a reviewed wrapper:

- HTML / CSS / JS / Canvas
- Phaser or similar web game libraries
- Godot HTML5 export
- Other small web exports a reviewer can open without installing Windows-only engines

MUGEN / Ikemen packs are **not** the submit path for the public terminal. Those belong on an optional fighter cabinet and must follow [`mugen.md`](mugen.md) and [`ikemen-go.md`](ikemen-go.md).

## Must

- Original or clearly licensed assets (no ripped commercial sprites or music)
- Keyboard and HID-stick friendly; match A / B / Start roles used on the terminal
- A way back to the terminal (Start / Exit) — no trapping kids in fullscreen with no quit
- Language and content appropriate for youth centers
- Author name the kid or volunteer wants on the card

## Must not

- Commercial ROM packs or “MUGEN full games” built from Capcom / SNK / anime rips
- Downloads that require a separate paid engine license we do not have
- Network features that phone home with kid data

Reviewers reject on legal or safety grounds first, polish second.
