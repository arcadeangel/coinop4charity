# TIC-80

Tiny fantasy console. Original carts only.

[TIC-80](https://tic80.com) is an open-source PICO-8–style machine: one cart, code + sprites + map + sound. Games can run in a browser or as a small binary.

We use TIC-80 instead of requiring PICO-8 so we are not tied to a paid engine license or a pile of commercial carts.

Coin Op 4 Charity is not affiliated with TIC-80.

## Floor

| | |
|--|--|

| Kid submit? | **Yes — original carts only** |
| What we run | Player’s own `.tic` / HTML export |

## Rules

- The kid (or club) made the cart, or has written permission.
- No dumped PICO-8 / commercial fantasy-console libraries.
- Keep language and art youth-appropriate.
- Prefer the HTML export for Preview Lab so review matches every other HTML5 title.

## Not PICO-8

PICO-8 is a great tool and a paid product. We do not make it a required engine and we do not host random cart collections. If someone builds an original PICO-8 game and can legally export a playable web build, treat that as HTML5 and review it like any other page.
