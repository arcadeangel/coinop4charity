# Beginner game codes

These start the **live** terminal games.

## Game IDs

Someone on staff can run `startGame('ID')` in the browser console, or you just tap the tile.

| Code | Game |
|---|---|
| `fight` | Fight Palace |
| `kaiju` | Neon Kaiju |
| `runner` | Circuit Runner |
| `racer` | Neon racer |
| `cycles` | Light cycles |
| `ufo` | UFO |
| `fish` | Fishing |
| `yeti` | Yeti dash |
| `paddle` | Paddle / breakout |
| `nyan` | Nyan Cat IV |

## URL codes (add after the site address)

Base: `https://coinop4charity.org/`

| Code | Use |
|---|---|
| `?kiosk=1` | Cabinet. No on-screen buttons. Stick only. |
| `?arcade=1` | Same as kiosk. |
| `?g=1` | AtGames Gamer Pro stick map. |
| `?gamerpro=1` | Same as `g=1`. |
| `?lite=1` | Weak tablet / Onn / low RAM. |
| `?lowram=1` | Same as lite. |

Examples:

```
https://coinop4charity.org/?kiosk=1
https://coinop4charity.org/?kiosk=1&g=1
https://coinop4charity.org/?lite=1
```
