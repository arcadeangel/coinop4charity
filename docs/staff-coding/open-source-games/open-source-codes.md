# CC0 game codes

These still exist inside `index.html` but have **no tile** on the live terminal. Staff can test, students can build using these as well these are CC0..

| Code | What it was | Start it? |
|---|---|---|
| `swarm` | Swarm shooter | `startGame('swarm')` |
| `worm` | Snake / worm | `startGame('worm')` |
| `rocks` | Asteroids-style | `startGame('rocks')` |
| `shiprekt` | Leftover boat game | init only — no clean start tile |

Do not add these back to the public grid at a club site unless someone playtested them.
